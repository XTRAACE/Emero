# EMERO — Intelligent Emergency Response

An intelligent emergency-response platform designed to connect people, emergency vehicles, hospitals, and responders through real-time coordination, location intelligence, and AI-assisted decision support.

🌐 **Live Site:** [KBonDev.github.io/emero-website](https://KBonDev.github.io/emero-website/)

## About

EMERO is a student-led research and prototype project focused on improving emergency-response coordination. It is **not** a replacement for official emergency services.

## Tech Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Build:** Vite
- **Design:** Custom design system, responsive, accessible
- **Maps:** SVG-based interactive visualizations
- **Deployment:** GitHub Pages via GitHub Actions

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

This is a research prototype. All data shown on the website is demo/sample data and is clearly labeled as such.
